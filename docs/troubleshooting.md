# Troubleshooting

## 자동 찾기가 실패할 때

HUSKYLENS 2 화면에 표시되는 MCP 주소를 직접 입력합니다.

웹앱은 마지막으로 성공한 주소가 있으면 먼저 자동 연결을 시도합니다. 이 연결이 느리면 자동 찾기도 함께 시작합니다. Wi-Fi가 바뀌었거나 HUSKYLENS가 재부팅된 뒤에는 저장된 주소가 맞지 않을 수 있습니다. 자동 연결이 실패하면 저장된 주소를 지우고 자동 찾기로 이어집니다.

자동 찾기는 수업 중 오래 멈춰 있지 않도록 짧게 실행됩니다. 같은 Wi-Fi에 있어도 학교 네트워크가 느리거나 장치 간 통신을 막으면 직접 입력이 더 빠릅니다.
VPN이나 가상 네트워크가 켜져 있으면 자동 찾기 대상에서 제외될 수 있으니, HUSKYLENS 화면의 MCP 주소를 직접 입력하세요.

자동 찾기에서 장치가 보이면 발견된 장치를 누릅니다. 누르면 주소 입력 없이 바로 연결됩니다.

예:

```txt
http://192.168.1.23:3000/sse
```

확인할 항목:

- HUSKYLENS 2 펌웨어가 V1.1.6 이상인지 확인
- Wi-Fi 모듈이 장착되어 있는지 확인
- HUSKYLENS 2와 PC가 같은 Wi-Fi에 연결되어 있는지 확인
- HUSKYLENS 2에서 `MCP Service`가 켜져 있는지 확인
- 학교 Wi-Fi가 장치 간 통신을 막는지 확인

MCP URL은 Wi-Fi에 따라 바뀔 수 있습니다. 이전에 성공한 주소가 다음 실행에서도 맞는다고 가정하지 마세요.

## operation 파라미터 오류가 날 때

HUSKYLENS 2 MCP 도구는 자유 문장 파라미터가 아니라 `operation` 기반 파라미터를 요구합니다.

인식 결과는 다음 순서로 호출해야 합니다.

```json
{ "operation": "current_application" }
```

그 다음 현재 알고리즘 ID를 사용합니다.

```json
{ "operation": "get_result", "algorithm": 2 }
```

앱은 이 흐름을 백엔드에서 처리합니다. 같은 오류가 다시 보이면 개발 서버를 재시작하세요.

## 이미지 주소가 열리지 않을 때

HUSKYLENS 2가 결과 이미지 URL을 `http://192.168.88.1/...` 형태로 반환할 수 있습니다.

현재 Wi-Fi에서 MCP URL이 `http://10.x.x.x:3000/sse`라면 브라우저나 서버는 `192.168.88.1`에 접근하지 못할 수 있습니다. 앱은 반환된 이미지 URL의 호스트를 현재 MCP 호스트로 자동 보정합니다.

## 화면이 느리게 갱신될 때

- HUSKYLENS 2와 PC가 같은 공유기에 연결되어 있는지 확인
- 학교 Wi-Fi에서 장치 간 통신이 제한되는지 확인
- 허스키렌즈와 노트북을 공유기 가까이에 두고 다시 연결
- HUSKYLENS 2의 `Video Streaming > RTSP Streaming`이 켜져 있는지 확인
- `npm install`이 끝났는지 확인하고, 별도 ffmpeg를 쓰는 경우 `FFMPEG_PATH`가 맞는지 확인
- 화면 상단의 다시 연결 버튼으로 영상을 한 번 다시 열기
- 계속 느리면 `일시정지` 후 다시 `영상 보기`

앱은 큰 화면을 인식 결과 이미지로 대체하지 않습니다. 큰 화면은 HUSKYLENS RTSP 스트림을 로컬 백엔드에서 받아 표시하고, 일반 질문은 MCP 인식 결과를 가져옵니다.

## 질문했는데 장면 수신이 지연될 때

- 허스키렌즈 화면에 현재 앱이 켜져 있는지 확인
- 카메라가 대상을 보고 있는 상태에서 다시 질문
- 웹앱의 영상 다시 연결 버튼을 한 번 누른 뒤 다시 질문
- 같은 문제가 반복되면 HUSKYLENS MCP Service를 껐다가 다시 켜고 재연결

## OpenAI 응답이 실패할 때

- API 키가 올바른지 확인
- 모델명이 `gpt-5.4-mini`인지 확인
- 네트워크에서 `api.openai.com` 접속이 가능한지 확인
- 결제 또는 사용 한도가 남아 있는지 확인

## 포트가 이미 사용 중일 때

```bash
npm run doctor
```

`doctor`는 Node.js, `.env`, API 키 상태, 로컬 앱 주소, 서버 응답, 자동 찾기 응답 시간, 연결 없는 질문/화면 요청 차단 상태를 보여줍니다. 로컬 서버나 핵심 API 계약이 깨지면 실패 코드로 끝납니다.

`8787` 또는 `5173` 포트가 이미 사용 중인데 앱이 열리지 않으면 해당 프로그램을 종료한 뒤 다시 실행합니다.
